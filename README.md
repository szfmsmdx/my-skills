# My Skills

个人维护的 Agent Skills，逐步积累写作、编辑及其他工作中可复用的方法。

## 当前 Skills

| Skill | 用途 |
| --- | --- |
| [concise-tech-docs-zh](concise-tech-docs-zh/SKILL.md) | 撰写和精简中文技术文档，保留正确性与论证，减少过度解释，使用图表和简洁列表。 |
| [humanizer-zh](humanizer-zh/SKILL.md) | 润色中文文章、评论和文档，减少空话与模板化表达，保留事实、确定程度和作者声音。 |

## 使用与扩充

将需要的 skill 目录复制到所用工具的技能目录，保留 `SKILL.md` 及其附带资源。

新增 skill 时，在根目录下建立独立文件夹，以 `SKILL.md` 作为入口，并更新上表；按需添加脚本、参考材料或测试。
