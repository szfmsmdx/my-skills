# 简明中文技术文档

根据读者已有知识和文档目的，说明问题、依据与结论，减少不影响理解的文字。

只展开读者尚不掌握、前文尚未说明且理解当前问题必需的内容；即使一句话本身有用，重复已知信息也应删去。

## 正确性优先

- 事实正确、含义完整和推理成立，优先于篇幅短、句子短或排版整齐。
- 简化后保留原文的对象、条件、范围、关系、数量和确定程度；删除这些信息会改变意思时，保留原表达。
- 区分事实、假设、推断、建议和既定决定，使用与证据相称的语气，不互相替换。
- 不为补齐论证而编造材料；发现疑点时核对可用依据，无法确认就保留不确定性或说明缺口。
- 尊重用户已定内容和编辑范围。表达优化不等于重新决策，也不授权增加任务、参数或验收要求。

## 写作思路

论证型文档默认按以下逻辑展开；这是内容之间的关系，不要求逐项设置标题。

1. **背景、已有知识与数据。** 交代问题、目标和理解论证必需的概念，列出可用事实与依据；将假设与已知事实分开。
2. **推理。** 说明依据怎样支持判断，保留关键计算、比较和因果环节，不用结论复述代替论证。
3. **结论。** 回答最初的问题，说明适用范围；结论强度不超过证据，交代尚不能确定的部分及原因。
4. **附录与补充。** 按需放详细推导、原始材料、完整代码、操作细节和次要边界，并从正文引用。

决定结论是否成立的条件、重要例外和影响执行的约束，应留在相应论证或结论附近，不能只藏在附录。共同前提可以集中说明，各项独有的依据和条件就近交代；不要求所有来源与假设只出现一次。

短答、操作说明或用户指定结构时，按任务需要组织，不补造背景、推理或附录。

## 通用简化方法

- **按信息作用取舍。** 每段提供新的依据、推理或结论，删除开场、强调、旁白和没有新增信息的解释。
- **缩短表达，保留含义。** 用准确的动词替代空泛的动词短语；能用常用词准确表达时，不堆砌抽象名词或修饰语。
- **合并重复，保留区别。** 前文已说明或读者可直接推得的内容不再复述；条件、对象或证据不同的信息不能合并成一个结论。
- **信任读者已有知识。** 沿用已建立的概念和上下文，只补关键缺口，保留推理中不显然的环节。
- **按影响选择提醒。** 只保留会改变判断或行动的限制，省去常识性告诫、反复免责，以及对读者未提出误解的预先辩护。
- **达到目的即停止。** 回答到问题所需深度，不自行扩展相邻主题、重复总结或追加防御性说明。
- **简化后检查歧义。** 指代、术语和表示法保持一致；缩写、换算或概括只有在等价且不影响判断时采用，不设固定词表、句式或单位写法。

## 结构化展示与排版

根据内容关系选择展示方式，让读者容易定位、比较和追踪信息；保留解释因果与条件所需的文字。

- **流程用图。** 多步骤、分支或交互过程优先考虑流程图或时序图，保留方向、条件和依赖，节点文字简短。
- **图要能直接阅读。** 使用交付环境支持的图形；无法渲染时用文本图，不只提供需要读者自行渲染的源码。
- **比较用表格。** 将同维度的对象并列，单元格用值或短语，必要解释就近补充，避免把长段落塞进表格。
- **并列项用无序列表。** 每项只表达一个要点，尽量用一个短句说清，重点和句式保持一致。
- **步骤用有序列表。** 仅在存在先后、依赖或优先级时编号，每项写清动作及必要条件。
- **列表项保持简洁。** 一项需要长篇解释时，改用段落或拆开独立要点，减少嵌套；不为缩短条目删掉关键限定。
- **重点少量强调。** 用加粗突出结论、关键词或关键数值，斜体用于少量术语或补充说明，避免整段强调。
- **排版留出层次。** 段落围绕一个主题展开，在标题、段落、图表和列表之间留白，避免标题过密。

图表或列表已经表达清楚的内容，正文只补充解读和必要条件，不再逐项复述。

## 编辑与交付

1. 读取现稿、用户要求和可用材料，确认已定事实、结论及需要保留的限制；共享文档写入前读取最新稿。
2. 先检查论证关系，再压缩重复与冗词。只做润色时，不擅自重排结构或补写论据。
3. 对照原文和依据核对：是否改变条件、混淆信息性质、丢失推理步骤或扩大结论；数值、引用及可执行内容是否仍然准确。
4. 通读确认依据能够导向结论，图表和列表便于扫读、条目简明。简化使含义含混时，恢复必要细节。

用户只要求审阅时给建议，明确要求修改时再写回。代码、命令、路径、字段、URL 和配置等可执行或可引用内容，未经授权不因文风改写；技术修改须符合实际执行环境。

默认交付成稿；需要汇报修改时，简短说明结果，不附自评分或重复编辑过程。

## 参考原则

- [George Orwell：Politics and the English Language](https://www.orwellfoundation.com/the-orwell-foundation/orwell/essays-and-other-works/politics-and-the-english-language/)：先弄清要表达的意思，再选择准确措辞，删去不必要的文字；不机械执行文风规则。
- [Google Technical Writing：Short sentences](https://developers.google.com/tech-writing/one/short-sentences)：围绕一个主要意思组织句子，删除冗词，改写时保持原意。
- [Microsoft Style Guide：Use simple words, concise sentences](https://learn.microsoft.com/en-us/style-guide/word-choice/use-simple-words-concise-sentences)：选用含义准确的常用词和动词，统一术语，保留影响含义的修饰语。
- [hardikpandya/stop-slop](https://github.com/hardikpandya/stop-slop/blob/main/SKILL.md)：参考其删铺垫、去模板化结构和直接陈述的做法；不采用一律禁用副词、被动句、标点或按分数验收等硬性限制。

以上是表述方法的参考；本文的论证顺序与正确性约束按用户要求制定，优先于外部文风建议。
